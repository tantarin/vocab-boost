# Фраза — мини-прототип

PWA-приложение для изучения полезных русских фраз и выражений: карточки, примеры употребления, мини-тест, прогресс и личная коллекция.

## Запуск

В папке проекта выполните:

```bash
python3 -m http.server 8080
```

Откройте `http://localhost:8080` в браузере.

## Установка на iPhone

Разместите папку на любом HTTPS-хостинге (например, GitHub Pages или Netlify), откройте адрес в Safari, нажмите «Поделиться» → «На экран Домой».
